# Vyro Lite

Bootable command-centre kernel.

## One-click free deploy (Render)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/naikarindam11-del/vyro-lite)

1. Click the button.
2. Sign in to Render with GitHub (free, no card).
3. Apply the blueprint (`render.yaml`).
4. Open `https://<service>.onrender.com/?token=<AGENT_TOKEN>` from the Render env vars.

The first request after idle can take ~1 minute. Disk on the free plan is ephemeral.

Repo: https://github.com/naikarindam11-del/vyro-lite
